Serie de apuntes/tutorial para aprender Rust desde cero, pensada para alguien que ya sabe programar (especialmente en C/C++) y quiere entender tanto la teoría como la práctica.

## Cómo usar estos apuntes

El **Tema 1** es puramente teórico: no hay que escribir código, es para entender el "por qué" de Rust antes de tocar el "cómo". A partir del **Tema 2** el formato es tutorial: cada tema tiene teoría breve + ejemplos ejecutables + ejercicios.

Se recomienda tener `rustc` y `cargo` instalados (ver Tema 2) y seguir los ejemplos escribiéndolos a mano, no copiando y pegando.
