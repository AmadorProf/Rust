## Cómo usar estos apuntes

El Tema 1 es puramente teórico: entiende el "por qué" de Rust antes de tocar el "cómo". A partir del Tema 2 el formato es tutorial: teoría breve + ejemplos ejecutables + ejercicios.

Las soluciones están dentro de cada `.md`, plegadas al final (`<details>`). Intenta resolver antes de abrirlas.

Se recomienda tener `rustc` y `cargo` instalados (ver módulo 02) y escribir los ejemplos a mano en vez de copiarlos y pegarlos.
